# Game Dev Student

**Game engines, learning paths, and jam platforms for students** — Godot, Unity student license, itch.io, and major online jams. Official store pages only.

> **Scams:** Fake “publish your game for a fee” services — use [itch.io](https://itch.io/) and engine docs directly.
